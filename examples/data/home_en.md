This wiki ships with [Flask-Wiki](https://github.com/rero/flask-wiki): every page is a plain Markdown file on disk, and the folder tree gives the URL tree.

## Where to start

1. [[guides/editing|Editing a page]] — metadata, Markdown, links and images.
2. [Managing languages](/help/guides/languages/) — one file per language, and the fallback when a translation is missing.

## Try the multilingual side

This page exists in French, English and Italian, the other ones do not. Switch language at the bottom of the page: the wiki then serves the first available translation and says so in a banner, rather than answering with a 404.
